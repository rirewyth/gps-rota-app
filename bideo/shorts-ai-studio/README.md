# Shorts AI Studio - Dashboard

Bu proje, `video.md` dokümanındaki gereksinimlere (özellikle madde 4 ve 5) uygun olarak hazırlanmış modern, karanlık (dark) arayüzlü bir Next.js + Tailwind CSS projesidir.

## Özellikler

- **Tasarım Felsefesi:** Premium, minimal, karanlık arayüz, profesyonel (Madde 4).
- **Ana Panel (Dashboard):** Sol menü (Sidebar) ve ana alandaki istatistikler, hızlı işlemler (Madde 5).

## Kurulum ve Çalıştırma

Gereksinimler: Node.js yüklü olmalıdır.

```bash
# Proje klasörüne girin (eğer içinde değilseniz)
cd bideo/shorts-ai-studio

# Geliştirme sunucusunu başlatın
npm run dev
```

Tarayıcınızda `http://localhost:3000` adresine giderek arayüzü görüntüleyebilirsiniz.
